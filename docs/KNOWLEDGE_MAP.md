# 知识领域与联系

知识星图回答：当前库有哪些领域？有哪些资料、方法、公式和实验？某个思路参考了谁，又被哪些实验使用？

启动本地服务后访问 http://127.0.0.1:8765/knowledge 。页面与实验脉络页互相链接，real/demo 分开。
无需显卡、额外模型或网络图形依赖。沿用 scripts/route_viewer.py。

## 分类与更新

- 新资料、方法、公式、方案、数据或路线节点入库后，打开的页面每 3 秒检查更新。后台标签页暂停轮询，重新打开立即检查。
- 没有分类的知识立刻进入“待分类”。系统不会用标题相似度编造关系。
- Agent 读取资料并确定归属后，通过 classify_knowledge 保存分类。一个记录可属于多个领域。
- 分类字段：target={id,version}，domains=[领域名称]，rationale=分类理由；更新时传 expected_version。
- 分类是记录者报告的元数据，不是论文作者确认，也不是科学验证。空列表撤销当前分类，旧版本仍可追溯。
- 分类针对精确版本，新版本不静默继承。已有引用指向的旧知识版本会保留在图上并标为历史。
- get_knowledge_graph 返回全图、领域、引用边和 revision。没有搜索结果 250 条截断。
- 当前领域名是人工维护的标签；建议复用已有名称，避免同义词造成重复领域。尚未提供自动领域识别、语义相似关系和领域层级推断。

## 阅读关系

实线箭头从“使用依据的记录”指向“被引用记录”，不是因果、支持或反驳判断。
虚线连接明确登记的领域归属；空间上的远近只是排版，不表示相似度。
点击节点查看领域理由、版本、来源、引用和被引用对象。点击归档来源可核验哈希并预览文件。
页面只读；真实科研判断的原有写入限制不变。图只涵盖新领域资料库，旧摘要库不会被伪装为已导入全文知识。

## 演示与检查

运行选定 Python 环境中的 python scripts/knowledge_demo.py，仅生成合成 demo 分类。
访问 http://127.0.0.1:8765/knowledge?namespace=demo 查看四个领域与实验联系。
可在 demo 中登记一个新资料文件，保持网页打开，最多约 3 秒后出现在待分类区域。
测试覆盖精确版本、分类更新冲突、命名空间隔离、超过 250 条记录和 HTTP revision 变化。
