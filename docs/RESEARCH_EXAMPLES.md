# 科研案例：从记录到行动建议

本文所有情境和结果分支均为虚构教学例子，不是运行结果，也不是可直接套用的实验方案。它们用于解释通用研究记录的用途；真实研究必须由领域专家核对设计和条件。现有默认 demo 仍是空间研究的合成场景，本文案例未被实现成额外可执行数据集。

## 一个完整例子：是否继续扩大机器学习模型？

### 1. 研究者提出问题

“模型 A 在当前测试集得分更高，是否值得把剩余预算用于扩大它？”

### 2. Agent 应先恢复哪些状态

| 记录 | 假想内容 | 不能直接推断什么 |
| --- | --- | --- |
| ResearchState | 目标是对新受试对象的泛化；预算只剩一次训练 | 当前测试得分就是目标能力 |
| Evidence | 实验报告只提供按样本随机划分的得分；尚未核对对象重叠 | 已证实存在泄漏，或已证实没有泄漏 |
| MethodClaim | 当前评价流程能估计目标泛化能力，状态 unresolved | 指标更高即可确认机制或可迁移能力 |
| Hypothesis | A 学到了可迁移的信息，状态 unresolved | 原报告的解释已被独立核实 |
| Decision | 上次约定先固定评测支撑，再比较容量 | 该决定永远不可改变 |
| OpenQuestion | 对象级重叠、调参过程及独立测试是否核对？ | 未登记意味着相关工作从未发生 |

Agent 应读取实际对象版本，并先询问或核对缺失信息。上表不是允许它编造这些记录的模板。

### 3. 形成竞争解释和可审查建议

可能解释包括：A 确实改善目标泛化；A 利用了跨划分重复信息；差异来自调参或评价不一致。解释可以共存。

一个符合工作流的建议是：

> 当前得分尚不能回答“对新对象是否有效”。先核对划分与调参记录；若确有对象重叠，优先比较固定、无对象重叠的评测条件。若核对成本低，应先检查已有产物，再决定是否消耗最后一次训练预算。现阶段不把扩大模型当成已接受决定。

其中“先查已有产物”受预算约束影响；“统一评测”受 MethodClaim 缺口影响；“不自动扩大”来自目前没有足够决策证据。知识库没有替 Agent 求解优化问题。

### 4. 新结果怎样改变下一步

| 假想后续情况 | 应审查的判断 | 合理的记录方向 |
| --- | --- | --- |
| 发现对象重叠，修正后优势不再清楚 | 原评价流程能否支持目标泛化结论 | 降低对原证据的依赖；机制/能力假设仍可能未决 |
| 修正后仍有优势，但只覆盖单一数据来源 | 已测条件内的比较与跨来源泛化分别判断 | 限定支持范围，不写成普遍有效 |
| 两种方法差异区间很宽 | 精度是否足够，不等同于“没有效应” | 保留 unresolved，评估能否补资料或缩小目标 |
| 新数据与旧结论冲突 | 来源、条件、版本、观察与解释是否可比 | 同时保留两条证据，说明冲突与重开条件 |

这些更新需要一条明确的“观测 → 解释 → 判断变化 → 决策”记录链。当前可以在 demo 演示，真实链尚不能提交。

### 5. 下一个会话为什么有用

下次用户问“为什么还没扩大模型？”时，Agent 应检索此前 Decision 的版本与来源，解释当时的证据缺口、预算条件和重开条件，而不是只说“之前决定不做”。

如果新条件已经满足，应提出重开原决策，而不是机械服从历史记录。ResearchMemory 应包含经验适用的上下文与例外，不能变成无条件禁令。

## 材料研究：分离测量证据与机制解释

假想问题：“新处理样品的信号更大，是否证明处理改善材料性能？”

1. Evidence 登记仪器报告及来源定位；若只读摘要就如实标记。
2. ResearchState 记录样品制备、批次和测量条件中已知与未知的部分。
3. Hypothesis 区分材料变化与测量/处理过程变化等解释。
4. MethodClaim 记录该信号在什么条件下能用于评价目标性能。
5. Experiment 应说明哪项对照使不同解释产生不同预期；具体设计须由领域专家确认。
6. 若条件变化解释了部分差异，更新的是限定条件下的证据解释，不自动认定材料机制不存在。

帮助在于显式暴露推理缺口、保存对照选择的理由，而不是让软件替代材料知识和实验判断。

## 观测研究：分离真实变化与观测过程

假想问题：“某地区生态记录减少，是否说明真实数量下降？”

先登记观测覆盖、努力程度、检测条件与数据缺口。如果同期观测方式改变，Agent 应保持多个解释，说明现有数据是否足以区分。缺少识别条件时，可以建议补充观测或降低结论强度。

后续新增资料时，应记录其时间与地点支撑，检查是否能与旧资料比较。对特定范围的判断不能无条件迁移到其他时期或地区。

## 可以直接给 Agent 的提问

```text
根据当前已登记状态，列出支持与反对当前解释的证据。
请给出对象 ID、版本、来源阅读深度；缺失的内容标为未登记。
```

```text
比较两个候选实验：分别能区分哪些解释、成本是什么、
得到什么结果会改变当前选择？先不要把建议写成已接受 Decision。
```

```text
检查这份新结果影响了哪些方法判断或机制解释。
把直接观察与推断分开，说明需要复核的旧记录及引用版本。
真实更新接口未开放时，仅输出待审查提案，不写入。
```
